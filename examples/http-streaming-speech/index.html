Streaming speech over HTTP

BoxLang aiSpeakStream() sends audio to your browser while the provider is still generating it.

The server streams raw mp3 bytes. The browser's own <audio> element plays them as they arrive. No JavaScript player is needed.

A streamed response has no known length, so the player cannot show a total duration. That is normal for live audio.

The server streams the aiSpeakStream() events as newline-delimited JSON: base64 PCM chunks plus word timestamps. This page schedules each chunk with the Web Audio API and lights up the words as they are spoken. Stop aborts the request, which closes the provider connection (barge-in).

Cartesia sends word timestamps. Other providers stream audio only, so the words panel stays empty for them.

Demo only: the endpoints spend your provider credits for anyone who can reach them. Add authentication and rate limits before exposing them.
